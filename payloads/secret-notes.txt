This file was uploaded as a plain text note and forced to `Content-Type: text/plain`
by the upload handler, exactly like the avatar was forced to `image/png`.

The bytes of this file are 100% innocent. Nothing here is a payload.

The point: Content-Type is only stored metadata on the object. Whoever decides
what header the browser receives at serve time decides how these bytes are
interpreted.  -- end of note --
